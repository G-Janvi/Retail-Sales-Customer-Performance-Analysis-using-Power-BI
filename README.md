# 📊 Retail Sales & Customer Performance Analysis (Power BI)


## 📌 Project Overview
This project analyzes retail sales data to uncover insights related to sales performance, customer behavior, and product trends using **Power BI**.


The dashboard helps stakeholders understand **which regions, products, and customer segments drive the most revenue and profit**.


---


## 🎯 Business Objectives
- Track overall sales and order performance
- Identify top-performing regions and products
- Analyze customer demographics and buying behavior
- Support data-driven business decisions


---


## 🧰 Tools & Technologies
- Power BI Desktop
- Microsoft Excel
- DAX (Basic Measures)
- GitHub


---


## 📂 Dataset Description
The project uses an Excel file with three tables:


- **Sales_Data**: Order-level sales transactions
- **Customer_Data**: Customer demographics
- **Product_Data**: Product details and cost price


Data is modeled using a **star schema** for optimal performance.


---


## 📊 Key KPIs
- Total Sales
- Total Orders
- Profit
  

---


## 📈 Dashboard Pages
### 1️⃣ Sales Overview
- KPI cards for high-level metrics
- Sales by Region (Column Chart)
- Monthly Sales Trend (Line Chart)


### 2️⃣ Customer & Product Analysis
- Sales by Product
- Sales by Category
- Customer-wise Sales Table
- Interactive slicers


---


## 🔍 Key Insights
- The **East region** contributes the highest revenue
- **Electronics** is the top-performing category
- Repeat customers show higher average order value
  

---


## 🚀 How to Use
1. Download the Excel dataset
2. Open the `.pbix` file in Power BI Desktop
3. Refresh data if needed
4. Explore the interactive dashboard
